# Install Viewer

Open **Store** from the existing Primitive Launcher. Find **Viewer** under **Reading** or **Utilities** and tap **Get**.
After installation, open Viewer from the Launcher grid. Install or update **Files** to 0.1.1 or later to use
**Open in Viewer** from its file menu.
Swipe vertically or use the Kindle page buttons to scroll through a PDF.

## Install from a release ZIP

Download the ARMHF ZIP for a supported Kindle running firmware 5.16.3 or later. Compare its SHA-256 with the
checksum file attached to the release before extracting it. [Viewer releases](https://github.com/PrimitiveOS/kindle-primitive-viewer/releases)

Connect the Kindle over USB and copy the archive’s `viewer/` folder to the root of the Kindle drive. Copy
`documents/Viewer.sh` into the existing `documents/` folder. Eject the drive, return to the installed Launcher,
and open **Viewer**.
